# ESPGraveYard 

**ESPGraveYard** is a portable, dual-node cybersecurity and wireless research device running **GhostESP v2.1**. It offloads screen and touch UI processing to a primary display controller while delegating heavy radio, USB injection, and hardware tasks to an **ESP32-S3** expansion node trough **GhostLink**.

---

##  Key Features

-  **BadUSB & HID :** HID payloads and host-side control.
-  **Sub-GHz RF :** Analyze, capture, and replay across the bands.
-  **Bluetooth LE :** Scan, capture, and spoof BLE devices.
-  **NFC & Infrared :** Read, write, and replay NFC and IR signals.
-  **GPS :** GPS location logging saved directly to MicroSD.
-  **Network & Ethernet :** Wired attacks and live traffic interception.
-  **Platform & UI :** Control, extend, and theme the whole device.
